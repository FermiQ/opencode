# models.go

## Overview

The `models.go` file in the `internal/db` package is **auto-generated by sqlc**. Similar to `db.go` and the `*.sql.go` files, it should **not** be manually edited, as changes will be overwritten when `sqlc generate` is run.

This file defines Go struct types that correspond to the tables in the application's database schema. These structs are used by `sqlc`'s generated query methods to represent rows retrieved from the database and to pass data for insertion or updates.

-   `File`: Represents a row in the `files` table.

-   `Message`: Represents a row in the `messages` table.
    -   `ID (string)`: Primary key for the message.
    -   `SessionID (string)`: Foreign key linking to the `sessions` table.
    -   `Role (string)`: The role of the message sender (e.g., "user", "assistant", "system").
    -   `Parts (string)`: The content of the message, likely in a structured format (e.g., JSON) if it supports multiple parts or types of content.
    -   `Model (sql.NullString)`: The AI model used to generate the message, if applicable (nullable).
    -   `CreatedAt (int64)`: Timestamp of creation.
    -   `UpdatedAt (int64)`: Timestamp of last update.
    -   `FinishedAt (sql.NullInt64)`: Timestamp of when the message generation was completed, if applicable (nullable).

-   `Session`: Represents a row in the `sessions` table.
    -   `ID (string)`: Primary key for the session.
    -   `ParentSessionID (sql.NullString)`: Identifier for a parent session, if this is a sub-session (nullable).
    -   `Title (string)`: A title for the session.
    -   `MessageCount (int64)`: The number of messages in this session.
    -   `PromptTokens (int64)`: The total number of prompt tokens used in this session.
    -   `CompletionTokens (int64)`: The total number of completion tokens generated in this session.
    -   `Cost (float64)`: The estimated cost associated with the AI interactions in this session.
    -   `UpdatedAt (int64)`: Timestamp of last update.
    -   `CreatedAt (int64)`: Timestamp of creation.
    -   `SummaryMessageID (sql.NullString)`: Foreign key linking to a specific message that might act as a summary for this session (nullable).

Each field in these structs is tagged with `json:"..."` to specify how it should be marshalled to or unmarshalled from JSON, which is useful if these models are directly used in API responses or if configuration/data is handled in JSON format elsewhere.
