# message.go (in internal/logging)

## Overview

The `message.go` file, part of the `internal/logging` package, defines the data structures `LogMessage` and `Attr`. These structs represent a structured log entry, likely used for internal processing, storage, or for publishing log events via a pub/sub mechanism to other parts of the application (e.g., a TUI log viewer).

## Key Components

### Structs

- `LogMessage`: Represents a single log event with detailed information.
    - `ID (string)`: A unique identifier for the log message (its source or generation method isn't defined in this file, but likely assigned when a `LogMessage` is created).
    - `Time (time.Time)`: The timestamp when the log message was generated.
    - `Level (string)`: The severity level of the log (e.g., "INFO", "DEBUG", "WARN", "ERROR").
    - `Persist (bool)`: A boolean flag. If true, this suggests the message is important and should be persisted or prominently displayed, potentially bypassing filters in a log viewer UI. This corresponds to the `*Persist` logging functions in `logger.go`.
    - `PersistTime (time.Duration)`: Associated with `Persist`, this duration might indicate how long a persisted message should be displayed in a status bar or similar UI element.
    - `Message (string)`: The main log message string (tagged as `msg` for JSON).
    - `Attributes ([]Attr)`: A slice of `Attr` structs, representing structured key-value pairs associated with the log entry.

- `Attr`: Represents a single key-value attribute for a structured log.
    - `Key (string)`: The name of the attribute.
    - `Value (string)`: The value of the attribute.
